# Sentiment Analysis
A sentiment analysis web application developed as a thesis project to compare the performance of Naive Bayes 
and Support Vector Machine (SVM) in classifying YouTube comments into Positive, Negative, and Neutral sentiments.

## Project Overview
This project analyzes YouTube comments from a podcast featuring Niky Putra and Mario Caesar. The main objective is to compare
two machine learning classification methods:
* Naive Bayes
* Support Vector Machine

The models are evaluated to determine which method provides better sentiment classification performance.

## Features
* User registration and login
* Real-time sentiment prediction
* Sentiment history
* CSV data upload and analysis
* Sentiment visualization
* Model performance evaluation
* Comparison between Naive Bayes and SVM
* PDF report generation
